# Online Examination System 📝

A Java Swing GUI application built as part of the Oasis Infobyte Java Development Internship.

## About
An online examination system where users can login, update their profile, attempt an MCQ based exam with a countdown timer, and view their results.

## Features
- User login with username and password
- Update profile and password
- 5 MCQ questions
- 30 second countdown timer per question
- Auto submit when timer runs out
- Score calculation and grade display
- Logout functionality

## How to Run
1. Clone the repository
2. Open the project in IntelliJ IDEA or any Java IDE
3. Run `OnlineExam.java`
